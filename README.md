# 🧩 Puzzle Feed Generator

> Ubah fotomu jadi puzzle feed interaktif — mainkan, lalu unduh potongan-potongannya.

**Puzzle Feed Generator** adalah aplikasi web modern yang dirancang untuk membantu kamu mengubah foto biasa menjadi potongan-potongan puzzle grid yang estetis dan interaktif. Sangat cocok digunakan untuk merapikan tampilan *feed* media sosial (seperti Instagram) atau sekadar membuat konten visual yang unik.

---

## ✨ Fitur Utama

- **Unggah Gambar Mudah**: Unggah file foto pilihanmu dengan cepat langsung ke dalam aplikasi.
- **Pilihan Ukuran Grid Fleksibel**: Tersedia berbagai opsi ukuran pemecahan puzzle sesuai kebutuhanmu:
  - $3 \times 3$ (9 potongan)
  - $4 \times 4$ (16 potongan)
  - $5 \times 5$ (25 potongan)
  - $6 \times 6$ (36 potongan)
  - $7 \times 7$ (49 potongan)
  - $8 \times 8$ (64 potongan)
  - $9 \times 9$ (81 potongan)
- **Pratinjau & Unduh**: Lihat hasil potongan puzzle secara instan dan unduh hasilnya dengan mudah.
- **Desain Modern & Responsif**: Antarmuka bersih dengan tema gelap yang nyaman dipandang dan ramah pengguna.

## 🛠️ Memulai (Pengembangan Lokal)

Jika kamu ingin menjalankan atau mengembangkan proyek ini secara lokal di komputermu, ikuti langkah-langkah di bawah ini:

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/Pusc4l/puzzlefeed.git
   ```
2. **Masuk ke direktori proyek:**
   ```bash
   cd puzzlefeed
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Jalankan server pengembangan:**
   ```bash
   npm run dev
   ```
